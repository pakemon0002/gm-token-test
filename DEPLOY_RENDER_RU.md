# GM TOKEN — развёртывание для закрытого тестирования

## Важно

Этот репозиторий — временный **тестовый стенд**, не публичный релиз и не настоящая криптовалюта. GM/CR — только игровые единицы. До утверждения курса магазина, наград коробок и Daily Reward механизмы остаются отключёнными. Системы против сговора нескольких аккаунтов и резервных копий ещё недостаточно для открытого запуска.

**Render Free хранит SQLite на временном диске `/tmp`. При перезапуске, обновлении или после 15 минут простоя весь прогресс тестировщиков может исчезнуть.** Никому не обещайте сохранение балансов. Для постоянного тестирования нужно платное хранилище или переработка под PostgreSQL и повторные тесты.

## Подключить GitHub и Render

1. Создать **новый приватный** GitHub-репозиторий `gm-token-test` (не используйте чужой/существующий `holding-group`).
2. Загрузить содержимое этого каталога в корень репозитория, **не загружать `.env` и базы данных**.
3. В Render авторизовать GitHub, выбрать New → Blueprint и новый репозиторий. `render.yaml` создаст тестовый Node Web Service с проверкой `/api/health`. Выбрать Free.
4. В приватных настройках Render → Environment сохранить следующие переменные (не публиковать их в GitHub/чат):
   - `BOT_TOKEN` — токен из @BotFather.
   - `BOT_WEBHOOK_SECRET` — свой случайный секрет из 32+ латинских букв/цифр/`_`/`-`.
   - `OWNER_TELEGRAM_IDS` — два числовых Telegram ID владельцев через запятую; **ID, не username**.
   - `OWNER_TOTP_SECRETS` — объект JSON с приватными TOTP-секретами каждого владельца (генерировать и хранить раздельно, не отправлять в чат).
   - `PUBLIC_APP_URL` — точный HTTPS-адрес из Render, например `https://gm-token-test.onrender.com/` **после создания сервиса**. Если сервис уже запущен, сохранить переменную и перезапустить.
5. `BOT_POLLING=0`. Встроенный webhook сам регистрируется в Telegram при старте приложения и связывает меню бота с HTTPS Mini App. Не запускать второй polling worker одновременно.
6. Проверить `https://<адрес>/api/health`, затем в Telegram открыть `@gm_token_test_bot`, отправить `/start`, нажать «Открыть GM TOKEN».
7. В игре проверить UI обоих владельцев, Mining, Holding, ордера, обращения в поддержку. Использовать тестовые игровые балансы; данные могут сброситься.

## Если webhook не работает

Посмотреть Logs в Render: после запуска должна появиться строка `Telegram webhook configured.`. Если её нет, убедиться, что `BOT_TOKEN`, `PUBLIC_APP_URL` и `BOT_WEBHOOK_SECRET` установлены и сервис перезапущен. Не публиковать токены в логи, скриншоты или тикеты.

## Утверждённые и неутверждённые правила

Правила см. `docs/OPEN_DECISIONS.md` и `docs/SECURITY_AUDIT_2026-11-08.md`. До устранения блокирующих проблем не приглашать обычных пользователей, не подключать деньги, не открывать API для внешних интеграций.

## Отчётность

`npm test` запускает набор тестов. GitHub Actions запускает тесты при изменениях. Любые результаты тестов доказывают только проверенные сценарии и не заменяют внешнюю оценку безопасности.
