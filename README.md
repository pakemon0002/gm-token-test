# GM TOKEN v5 — краткая инструкция

Важное: этот ZIP — **исходники и тестовая новая сборка**, а не доказательство готовности к публичному запуску. GM/CR виртуальные, не реальные деньги.

## Проверка кода (Node.js 22.16+)

1. Распакуйте ZIP целиком, откройте папку проекта.
2. `npm test` — запускает 40 серверных и интеграционных тестов. Для этих тестов не нужны токены.
3. `npm start` — запускает сервер `http://localhost:8787`; для авторизации через Telegram потребуется настоящий `BOT_TOKEN` в приватном `.env`, а для webhook ещё и `PUBLIC_APP_URL`/`BOT_WEBHOOK_SECRET`.
4. Если необходимо пересобрать UI после правок `miniapp/src/main.tsx`: `cd miniapp`, `tsc -p tsconfig.standalone.json`, `cp src/styles.css public/styles.css`.
5. Доступ через Telegram Mini App без подписанных `initData` намеренно не выдает реальные игровые данные.

## Важные особенности

- Фиктивные балансы удалены. Регистрация: **0 GM + 5 000 CR** (согласованный разовый бонус CR), 0 Vault, 0 POINTS, Level 1.
- Первые 24ч **с момента создания новой базы** — Premarket с Limit-заявками. Цена открытия рассчитывается из спроса/предложения; до первой исполненной сделки реальные свечи пусты.
- Торговая цена — из матчинг-движка, не из POINTS. Реальная OHLCV по факту сделок, интервал 1m–1d.
- Новая версия **НЕ опубликована** в Render и боте. Текущая развернутая версия осталась прежней.

## Закрытый тест дополнительных механик

Для новых независимых тестовых данных: `GM_PRIVATE_TEST_ECONOMY=1` *при первом запуске новой БД*. Это включает предварительные тестовые значения, которые ещё не согласованы для релиза. См. `docs/GM_TOKEN_V5_RELEASE_NOTES_RU.md`.

## Вариант GitHub/Render

Для старого способа загрузки двух файлов используйте отдельный архив `GM_TOKEN_v5_GitHub_Render_Test_Kit.zip`, в нём будут `gm-token-source.tar.gz` и `render.yaml`, плюс инструкция. Новый Render проект может создать новую БД и начать новый 24ч аукцион. НЕ обновляйте существующую игровую базу/сервер на бесплатном хостинге без резервной копии и решения о сохранении данных.

Полный отчёт: `docs/GM_TOKEN_V5_RELEASE_NOTES_RU.md`.
