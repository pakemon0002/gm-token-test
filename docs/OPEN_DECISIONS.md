# GM TOKEN — решения, которые нельзя подставлять автоматически

Версия: предварительная перед запуском. Владельцы: Owner и Co-Owner с одинаковыми правами, фактические ID вводятся только в секретные настройки сервера.

| Функция | Уже утверждено | Не утверждено / статус сборки |
|---|---|---|
| GM Shop | Комиссия **1% GM**, лимит **50 000 CR/сутки**, все GM в Treasury | Точная формула динамического курса, критерий доверия ликвидности. Настройка `SHOP_RATE_MODE=disabled` до утверждения. |
| Holding | Вывод 5%, один в UTC-день, фактическое почасовое начисление, потолок **0,5%/день**, фонд/резерв | Точная не гарантированная ставка; `HOLDING_DAILY_BPS=0`, возможно 0..50 basis points, где 50=0,5% в день. |
| GM Boxes | Стоимость **300/750/1500 POINTS** | Суммы GM внутри каждого вида. `BOX_REWARDS_GM_JSON={}`. |
| Daily Reward | Ежедневная логика, фонд 13 млн GM на Daily/Tasks | Точная сумма и календарь Streak. `DAILY_REWARD_GM=0`. |
| XP/Tasks | Уровни и +20 XP за Mining Claim раз в сутки, подтверждение задач на сервере | Список заданий, XP и GM за каждое. Каталоги пустые. |
| POINTS | Только исполненные сделки: 10 POINTS на 10k GM, максимум1000/день | Истечение/сгорание POINTS не утверждено. Пока не истекают (временное поведение, не окончательное решение). |
| Auction | 24 часа, uniform clearing maximizing volume, partial order carry | Точный tie-break при эквивалентных объёмах/дисбалансах: сейчас выбирается медианная цена из равноправных кандидатов. Требует одобрения. |
| Co-owners | Два совладельца равноправны, нельзя понизить другого без защищённой процедуры | Конкретный раздел Founder Allocation (10 млн GM) между владельцами, дополнительное совместное одобрение изменения экономических правил. |
| Wash Trading | Самоторговля запрещена, подозрительные повторные сделки не дают POINTS | Настройка чувствительности и более сложная anti-collusion модель. Сигнал не является доказательством мошенничества. |

**Настройка тестового сервера:** примеры со ставкой Holding 10bp, Daily 10 GM, коробками 15/45/105 GM и Shop median95 встречаются исключительно в автоматизированных тестах. Они не активны в нормальной установке. После утверждения параметров следует добавить регрессионные тесты и поднять новую тестовую базу/миграцию, а не молча менять правила для игроков.
